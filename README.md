# DANIL / PERSONAL SPACE

Готовый адаптивный персональный сайт-знакомство. Тёмный графитовый интерфейс, фиолетовые акценты, одна фотография, кнопки Telegram и плавные анимации.

## Состав

```text
DANIL_PERSONAL_SPACE/
├── index.html          # Разметка сайта и SEO
├── styles.css          # Дизайн, адаптивность, анимации
├── script.js           # Мобильное меню, навигация, появление блоков
├── assets/
│   ├── danil-photo.webp # Одна фотография, оптимизированная для сайта
│   └── favicon.svg     # Значок вкладки
└── README.md           # Эта инструкция
```

## Быстрый просмотр

Распакуйте архив и откройте **index.html** в браузере. Для тестирования через локальный сервер можно использовать VS Code с Live Server либо выполнить в этой папке:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/ (для работы команды нужен установленный Python).

## Публикация на GitHub Pages (без сборки)

1. Создайте репозиторий на https://github.com/new, например `danil-personal-space`.
2. Загрузите **содержимое** папки `DANIL_PERSONAL_SPACE` в **корень** репозитория: `index.html`, `styles.css`, `script.js`, `assets/`, `README.md` (не вложенную папку целиком).
3. Откройте **Settings → Pages** в вашем репозитории.
4. В разделе **Build and deployment** установите **Source: Deploy from a branch**, затем **Branch: main** и **Folder: / (root)**. Сохраните.
5. После публикации сайт будет доступен по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/danil-personal-space/`. Конкретный адрес зависит от имени пользователя и репозитория.

Для репозитория с точным именем `ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io` сайт публикуется в корне домена. Конфигурация сборки не требуется. Все локальные файлы подключаются **относительными путями `./`**, поэтому сайт работает и в подкаталоге GitHub Pages без настройки `base`.

## Доступность и производительность

- Адаптация под мобильные, планшеты и компьютеры.
- Клавиатурная навигация, доступная кнопка меню и быстрый переход к содержимому.
- Поддержка `prefers-reduced-motion`, мягкие переходы и одноразовые эффекты появления.
- Фотография WebP; нет библиотек JavaScript и внешних CSS-фреймворков.
- Для шрифта Manrope используется Google Fonts; при отсутствии сети включается системный запасной шрифт.
- Нет форм, аналитики и сбора персональных данных посетителей.
